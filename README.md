从对话循环、工具调用和权限检查，到记忆、上下文管理与多智能体编排，理解一个 Agent 运行时如何协同工作。全书 15 章、4 篇附录，结合架构图、设计权衡与动手练习，逐步构建自己的 Agent Harness。

> *“一器而工聚焉者，车为多。”* ——《考工记》
>
> 两千年前，造车已是一项汇聚众工的系统工程：**舆**承载乘者，辕、辐、軎辖各司其职。部件相合，车方能行。
>
> 今天，构建一个 AI Agent 亦是如此：对话循环推进任务，工具系统执行动作，权限管线约束边界。而将这些能力承载、组织起来，使智能体持续运转的运行时框架——**Agent Harness**——恰如车之有**舆**。
>
> 古人造车，合众工之巧；今人构建智能体，亦需理解各部分如何协作。所谓“御舆”，既是驾驭，也是知其构造、明其机理。
>
> 本书因此以 **“御舆”** 为名，亦称 **舆书**。

## 开始阅读

- **初次阅读：** 从[前言](00-前言.md)开始，再读 01 → 02 → 04 → 15。
- **动手构建：** 先读基础篇与工程实践篇，增加记忆和扩展能力时查阅第二、三部分。
- **按需查阅：** 使用下方四篇附录定位模块、工具、功能标志和术语。
- **网站阅读：** [在线阅读入口](https://lintsinghua.github.io/)；也可直接点击本仓库的章节链接。

## 阅读说明

阅读时需区分源码可确认的行为、架构推演和教学示例。功能标志与工具可用性取决于构建和运行时配置；数量和耗时示例不代表当前发行版承诺。

Claude Code 为 Anthropic 产品，本书是独立的技术分析作品，并非官方出版物。本书的许可不覆盖第三方源码。

## 离线整书

`yuyu-book/` 把 20 个单元装配成**一本可离线阅读的书**：单文件 HTML（中文版 5.4 MB / 英文版 5.5 MB）与 A4 排版的 PDF（中文版 462 页 / 15.5 MB，英文版 499 页 / 9.8 MB），中英各一份，产物在 `yuyu-book/dist/`。

| 文件 | 语言 |
|------|------|
| `yuyu-agent-harness-zh.html` / `.pdf` | 中文 |
| `yuyu-agent-harness-en.html` / `.pdf` | English |

整书自带封面、版本与许可页、修订史、阅读路线、带页码的目录、**全书线路图**（目录之后自成一页：前言是路头的辐轮，十五章是蛇形路上依次排开的站圈，附录走虚线岔线）、分部过渡页与每篇题刻、每章「本章问题 / 读完交付 / 本章边界」罗盘与来源锚点、每版 157 张（中英合计 314）按书的配色预渲染的图版、代码块语言角标、脚注、来源与许可页和主题索引（中文版在 A–Z 之后另立「中文」词条块，只记得译名也查得到）；书里的装饰全是自绘矢量——扉页一辆四马古车、每单元一枚章徽、每篇一幅题刻，章眉下一条按单元 id 生成的手绘走线（20 章各不相同），章末两道渐次散开的车辙，分部过渡页横一条与章数一一对应的道路，提示块与小节分隔也各自带着手写墨记，没有一处用字体符号或图片素材凑数。宽屏（≥1360px）另有一列常驻侧栏目录，线路图在那里带一枚辐轮入口。PDF 另有侧边书签、页脚页码与奇偶不同的页眉，书末主题索引的每一行也印出它所指的那一页，正文里的「参见第 N 章」自动成为可点击链接。每一章都收在它自己结束的那张纸上——全书没有一张只剩页眉与页码的空页。太宽放不下竖版的图版会独占一张横向纸页，图里的文字在 PDF 里依然可选中、可检索。`KAIROS_GITHUB_WEBHOOKS`、`skipDangerousModePermissionPrompt`、`~/.claude/settings.json` 这类长名字在构建时自动获得断点：两端对齐的中文行不会被一根放不下的长名拉成字距空洞，纸面上也不会把整张表顶出版心（断点只落在 `_`、`/` 与大小写交界处，普通英文词永不被切断）。HTML 断网双击即可阅读——不加载任何外部字体、图片或脚本。

为第一次读这一类书的工程师，构建时还会叠一层**通俗层**（只叠加，不改写正文）：每章开头一句白话导读带加一个比方；术语首现处画虚线（若一个术语在该章只以行内代码现身，虚线就画在那段代码上——`AbortController` 这类只写作代码的词，读者第一眼撞上它时同样悬得出浮窗），屏幕上悬停出白话浮窗——一句白话定义、一句「为什么非这样不可」、一个比方，44 个主干术语的原理都取自正文自己的论证，纸面上另有书末「原理札记」一页按章收拢（屏幕上不够宽、或术语坐在要横向滚动的宽表里时，浮窗改钉在屏幕底部，免得被裁掉看不见），纸面上新词收在章末的面板，正文第一句仍落在开篇那一页；每个小节右上角盖一枚「起步 / 主干 / 进阶」徽，前言据此给出三条阅读路线。每章章末的车辙上方还坐着一位老驿卒：一行按语（全书 20 行，存在 `yuyu-book/notes.json`）用白话回头看他刚跑完的这一段，书末「按语集」一页把它们按阅读顺序收齐、每行链回自己那一章。按语不许长成第二份正文——**术语锁**要求每句都含一个已注册术语，且那个词形必须真正出现在它自己那一单元的正文里（拿第 14 章的话说「规划模式」，不能写只有别的章才用的词）；中文一句限 36 字、英文限 130 字符，英文版还不许夹汉字。全书另有 26 份手写线描图——扉页一幅四马古车、20 枚章徽配在章名右侧、4 幅题刻开在每篇首页、章末一枚驿卒的斗笠——只用 `currentColor` 描线，所以屏幕、暗色模式与纸面共用同一份图。通俗层可以整块用 `--no-plain` 关掉。

```bash
npm ci                                              # 图版渲染需要 Mermaid 11.17.2
python -m pip install -r yuyu-book/requirements.txt
python yuyu-book/build.py --check                   # 只校验，产物写入临时目录
python yuyu-book/build.py --lang zh                 # 仅 HTML
python yuyu-book/build.py --pdf                     # 中英双语 HTML + PDF
```

PDF 与图版渲染需要一个本机 Chromium 或 Edge（自动探测 `msedge`/`chrome`，也可用 `--browser <路径>` 指定）。正文 Markdown 是唯一事实来源，构建过程不回写、不改写任何章节文件。
